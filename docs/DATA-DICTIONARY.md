# 数据定义

刷卡事件以event_id去重，card保留前导零。route支持1路/01等别名。event_time必须带偏移；业务日为Asia/Shanghai。result仅success可作为行程，失败刷卡隔离。reported为实扣人民币元。票价F1至2026-11-01前为2元，F2为2.50元。

线路分一票制与分段计价两种，登记在`app/modules/m2_routes/rules.py`（S1为分段计价）。分段计价线路要求上车、下车各刷一次：同一卡在同一分段线路上的连续两次成功刷卡配对为一个行程，只计一次费，行程完成时刻为下车刷卡时刻；行程实扣为两次刷卡reported之和，来源行保留两条。配对失败（缺少对应下车或上车的孤儿刷卡、被其他刷卡打断的未闭合登机刷）不丢弃、不强行合并：保留原记录，按旧版单次计费并标注"未配对"。金额无法核实（reported缺失或非法）的刷卡在票价阶段隔离并保留原值，其配对对象按孤儿处理。

换乘间隔裁决：以上一次实际付费行程的完成时刻为起算事实——分段计价行程的完成时刻是下车刷卡时刻，一票制行程是上车刷卡时刻（上车即完成）。换乘间隔=当前行程上车时刻−上一付费行程完成时刻，跨线路且在[0,60)分钟内给予1元换乘优惠，恰好60分钟排除。不以上车时刻起算，因为行程时长会被计入间隔，长途乘客刚下车的真实接续会被错误排除；下车起算的续期风险由既有规则对冲：同线路无优惠、零付费行程不能延长换乘锚点、日封顶6元兜底。先扣换乘优惠，再对卡号业务日施加6元封顶。每条基本票价=实算扣费+换乘优惠+封顶优惠；每张卡每个业务日产生唯一的应收合计、换乘依据（锚点行程、锚点完成时刻、间隔分钟）与封顶结果。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
